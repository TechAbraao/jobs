Jobs CLI

CLI para buscar e analisar vagas da Gupy diretamente pelo terminal.

jobs-cli search [OPTIONS]

Busca vagas de emprego na plataforma Gupy com filtros de cidade, tipo de contrato e palavra-chave.

Busca básica

Busca padrão

jobs-cli search

Trazer mais resultados

jobs-cli search --limit=30

Trazer poucos resultados

jobs-cli search --limit=3

Por cidade

Rio de Janeiro

jobs-cli search --city="Rio de Janeiro"

Belo Horizonte

jobs-cli search --city="Belo Horizonte"

Recife

jobs-cli search --city="Recife"

Porto Alegre com mais resultados

jobs-cli search --city="Porto Alegre" --limit=20

Por tipo de vaga

Estágio

jobs-cli search --type="Estágio"

Jovem Aprendiz

jobs-cli search --type="Jovem Aprendiz"

Efetivo

jobs-cli search --type="Efetivo"

Por palavra-chave

Vagas de dados

jobs-cli search --keyword="Dados"

Vagas de suporte

jobs-cli search --keyword="Suporte"

Cargo específico

jobs-cli search --keyword="Desenvolvedor Python"

Combinando filtros

Estágio em tecnologia no Rio de Janeiro

jobs-cli search --city="Rio de Janeiro" --type="Estágio" --keyword="Tecnologia"

Vagas de dados efetivas em Belo Horizonte

jobs-cli search --city="Belo Horizonte" --keyword="Dados" --type="Efetivo" --limit=15

Erros comuns

Tipo inválido

jobs-cli search --type="CLT"
Error: Invalid value for '--type': 'CLT' is not one of 'Efetivo', 'Estágio', 'Estagiário', 'Jovem Aprendiz'.

Cidade com espaço sem aspas

jobs-cli search --city=São Paulo
Error: Got unexpected extra argument (Paulo)

Sempre envolva nomes com espaço em aspas: --city="São Paulo".

Referência de opções

Opção Tipo Padrão Descrição
--city str São Paulo Filtra vagas por cidade.
--limit int 10 Quantidade de resultados retornados.
--keyword str N/A Busca no título e descrição das vagas.
--type str Efetivo Tipo de vaga: Efetivo, Estágio / Estagiário, Jovem Aprendiz.

jobs-cli match [OPTIONS]

Busca vagas de emprego na plataforma Gupy utilizando os filtros disponíveis e calcula a porcentagem de compatibilidade de cada vaga com as palavras-chave definidas pelo usuário no arquivo KEYWORDS.md.

Executar análise

jobs-cli match

Definir palavras-chave

As palavras utilizadas na análise são definidas no arquivo KEYWORDS.md. 

Python
AWS
Docker
Git
SQL
Linux

Resultado

O comando calcula uma porcentagem de compatibilidade e apresenta as palavras-chave encontradas em cada vaga.

jobs-cli history [OPTIONS]

Permite visualizar o histórico de comandos utilizados, com a opção de limitar a quantidade exibida.

Visualizar histórico

jobs-cli history
