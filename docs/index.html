Jobs CLI

CLI para buscar e analisar vagas da Gupy diretamente pelo terminal.

v0.5.0

jobs-cli search [OPTIONS]

Busca vagas de emprego na plataforma Gupy com filtros de cidade, tipo de contrato e palavra-chave.

Referência de opções

Opção Atalho Tipo Padrão Descrição
--city -c str N/A Filtra vagas por cidade.
--limit -l int 10 Quantidade de resultados retornados.
--keyword -k str N/A Busca no título e descrição das vagas.
--state -s str N/A Filtra vagas por estado.
--type -t str Efetivo Tipo de vaga: Efetivo, Estágio e Jovem Aprendiz.
--output -o str N/A Nome do arquivo .txt para salvar os resultados (salvo em jobs/data/archives).
--enterprise -e str N/A Filtra vagas por empresa.
--remote -r N/A True Aplicar filtro para vagas remotas.

Armazenamento Local

Os arquivos .txt das ocorrências de vagas são armazenados por padrão em: 

jobs/data/archives/[NOME].txt

1. Busca básica

Para aumentar a quantidade de vagas retornadas, utilize a opção --limit (ou sua forma abreviada -l).

1.1. Flags disponíveis

jobs-cli search --help

1.2. Busca padrão

jobs-cli search

1.3. Trazer mais resultados

jobs-cli search --limit=30

Forma abreviada:

jobs-cli search -l 30

1.4. Trazer poucos resultados

jobs-cli search --limit=3

Forma abreviada:

jobs-cli search -l 3

2. Por cidade

Para filtrar por cidades específicas, utilize a opção --city (ou sua forma abreviada -c).

2.1. Rio de Janeiro

jobs-cli search --city="Rio de Janeiro"

Forma abreviada:

jobs-cli search -c "Rio de Janeiro"

2.2. Belo Horizonte

jobs-cli search --city="Belo Horizonte"

Forma abreviada:

jobs-cli search -c "Belo Horizonte"

2.3. Recife

jobs-cli search --city="Recife"

Forma abreviada:

jobs-cli search -C "Recife"

2.4. Porto Alegre com mais resultados

jobs-cli search --city="Porto Alegre" --limit=20

Forma abreviada:

jobs-cli search -c "Porto Alegre" -l 20

3. Por tipo de vaga

Para filtrar por tipos de vagas, utilize a opção --type (ou sua forma abreviada -t).

3.1 Estágio

jobs-cli search --type="Estágio"

Forma abreviada:

jobs-cli search -t "Estágio"

3.2. Jovem Aprendiz

jobs-cli search --type="Jovem Aprendiz"

Forma abreviada:

jobs-cli search -t "Jovem Aprendiz"

3.3. Efetivo

jobs-cli search --type="Efetivo"

Forma abreviada:

jobs-cli search -t "Efetivo"

4. Por palavra-chave

Para filtrar por palavra-chave, utilize a opção --keyword (ou sua forma abreviada -k).

4.1 Vagas de dados

jobs-cli search --keyword="Dados"

Forma abreviada:

jobs-cli search -k "Dados"

4.2. Vagas de suporte

jobs-cli search --keyword="Suporte"

Forma abreviada:

jobs-cli search -k "Suporte"

4.3. Cargo específico

jobs-cli search --keyword="Desenvolvedor Python"

Forma abreviada:

jobs-cli search -k "Desenvolvedor Python"

5. Combinando filtros

5.1. Estágio em tecnologia no Rio de Janeiro

jobs-cli search --city="Rio de Janeiro" --type="Estágio" --keyword="Tecnologia"

Forma abreviada:

jobs-cli search -c "Rio de Janeiro" -t "Estágio" -k "Tecnologia"

5.2. Vagas de dados efetivas em Belo Horizonte

jobs-cli search --city="Belo Horizonte" --keyword="Dados" --type="Efetivo" --limit=15

Forma abreviada:

jobs-cli search -c "Belo Horizonte" -k "Dados" -t "Efetivo" -l 15

6. Salvando as ocorrências em um arquivo .txt

6.1. Salvando ocorrências de vagas na cidade de São Paulo com a palavra-chave Python

jobs-cli search -c "São Paulo" -k "Python" -o Vagas.txt

jobs-cli match [OPTIONS]

Busca vagas de emprego na plataforma Gupy utilizando os filtros disponíveis e calcula a porcentagem de compatibilidade de cada vaga com as palavras-chave definidas pelo usuário no arquivo KEYWORDS.md.

Referência de opções

Opção Atalho Tipo Padrão Descrição
--file -f KEYWORDS.md KEYWORDS.md Arquivo de palavras-chave.
--keyword -k str N/A Busca no título e descrição das vagas.
--limit -l int 10 Quantidade de resultados retornados.
--enterprise -e str N/A Filtra vagas por empresa.
--state -s str N/A Filtra vagas por estado.
--city -c str N/A Filtra vagas por cidade.

Definir palavras-chave

Para utilizar o comando match, renomeie o arquivo KEYWORDS_TEMPLATE.md para KEYWORDS.md. O arquivo está localizado na raiz do projeto e deve permanecer nesse diretório. Em seguida, preencha-o com as palavras-chave que representam seus conhecimentos, tecnologias ou competências de interesse. Utilize o modelo abaixo como referência: 

Python
Java
Flask
FastAPI
Spring Boot
AWS
Amazon Web Services
Docker
Linux
Bash Script

1. Comandos básicos

1.1. Flags disponíveis

jobs-cli match --help

1.2. Buscar vagas no estado de São Paulo pela palavra-chave Java com cálculo de compatibilidade.

jobs-cli match -f KEYWORDS.md -s "São Paulo" -l 15 -k "Java"

1.3. Buscar vagas no estado do Rio de Janeiro pela palavra-chave AWS com cálculo de compatibilidade.

jobs-cli match -f KEYWORDS.md -s "Rio de Janeiro" -l 10 -k "AWS"

1.4. Buscar vagas na cidade de São Paulo com cálculo de compatibilidade e palavra-chave Python.

jobs-cli match -f KEYWORDS.md -k "Python" -c "São Paulo"

jobs-cli history [OPTIONS]

Permite visualizar o histórico de comandos utilizados, com a opção de limitar a quantidade exibida.

Referência de opções

Opção Atalho Tipo Padrão Descrição
--limit -l int 10 Número de comandos a exibir.

Armazenamento Local

O histórico é armazenado localmente utilizando SQLite. 

jobs/data/jobs.db

1. Comandos básicos

1.1. Flags disponíveis

jobs-cli history --help

1.2. Visualizar histórico

jobs-cli history

1.3. Visualizar histórico limitando a quantidade na saída

jobs-cli history --limit=30
